Деплой:
любого сайта

Универсальная сайт-инструкция: публикуем любой проект в интернете через Netlify Drop — промпт-проверка папки opencode, регистрация, drag-and-drop. Подходит для любого сайта: лендинга, портфолио, визитки. Старт — блок 1, правила агента: скиллы подхватываются окружением, не чтением, не консолью, не притворством. Затем публикация (блоки 2–4) и продакшен (блоки 5–10): ревизия навыком site-legal-audit-ru по живому URL → своё досье с навыками grillme и копирайтера-маркетолога → архитектура файлов (политика конфиденциальности и другие) → независимый аудит → рефакторинг с переопубликацией → безопасность: цикл «аудит → рефакторинг → аудит» под ключ. Готовых промптов десять; досье пишете сами. Прогресс сохраняется в браузере.
